Bases: Enum

DeleteError defines the set of delete error types.

INTERNAL = DeleteError.INTERNAL

DELETE_ERROR_INTERNAL indicates that the server encountered an unrecoverable error on the specified delete.

UNAUTHORIZED = DeleteError.UNAUTHORIZED

DELETE_ERROR_UNAUTHORIZED indicates that the user is not authorized to perform the specified delete.

UNDELETABLE_KEY = DeleteError.UNDELETABLE_KEY

DELETE_ERROR_UNDELETABLE_KEY indicates that the specified error is not allowed by the service.

UNSPECIFIED = DeleteError.UNSPECIFIED

DELETE_ERROR_UNSPECIFIED indicates that the delete error is not specified.
