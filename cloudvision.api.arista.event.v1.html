TimeRange allows limiting response data to within a specified time window. If this field is populated, at least one of the two time fields are required.

For GetAll, the fields start and end can be used as follows:

  • end: Returns the state of each EventAnnotationConfig at end. * Each EventAnnotationConfig response is fully-specified (all fields set).

  • start: Returns the state of each EventAnnotationConfig at start, followed by updates until now. * Each EventAnnotationConfig response at start is fully-specified, but updates may be partial.

  • start and end: Returns the state of each EventAnnotationConfig at start, followed by updates until end. * Each EventAnnotationConfig response at start is fully-specified, but updates until end may

    be partial.

This field is not allowed in the Subscribe RPC.
